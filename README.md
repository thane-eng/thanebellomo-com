# thanebellomo.com

Personal name hub. The product lives at https://thecourageeconomy.net.

## GoDaddy DNS

Point the domain at Vercel. After the project is live, Vercel will show the exact values. Typical records:

- `A` `@` → `76.76.21.21`
- `CNAME` `www` → `cname.vercel-dns.com`

Do not change nameservers unless you want Vercel to manage DNS. A and CNAME on GoDaddy is enough.
